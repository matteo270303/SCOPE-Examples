# CHAIN-OF-THOUGHT REASONING PROCESS
For EACH task in T_fe, follow these four steps before writing code:

Step 1 — TASK AND ENDPOINT REVIEW: Read the task description. Identify which API endpoints this page/component must consume. Look up those endpoints in C_be to confirm: exact route, HTTP method, request body format, response JSON structure, and authentication requirements (JWT or public).

Step 2 — IMPORT RESOLUTION: Determine all required imports:
  - From React/Next.js: useState, useEffect, use, Link, useRouter, usePathname
  - From local components: verify the exact file name and relative path (count directory levels carefully)
  - From context: useAuth if authentication state is needed
  - From lib: API client wrapper functions
  - From external libraries: lucide-react icons, recharts charts, shadcn/ui components

Step 3 — PLAN COMPONENT STRUCTURE AND DATA FLOW: Before writing JSX, outline:
  - State variables: what data is fetched, loading/error states
  - useEffect: which endpoints are called on mount, with what parameters
  - Event handlers: form submissions, button clicks, navigation actions
  - Conditional rendering: loading skeleton, error message, empty state, data display
  - Responsive breakpoints: mobile layout vs. desktop layout

Step 4 — GENERATE IMPLEMENTATION: Write the complete code, interleaving reasoning comments with executable JSX (Chain-of-Code approach).

# CHAIN-OF-CODE PROMPTING
You MUST interleave brief reasoning comments with code. Each logical section (state, data fetching, event handlers, render blocks) should be preceded by a comment explaining WHAT it does and which endpoint/component it interacts with.

Example of Chain-of-Code in a page component:
```jsx
'use client';
import { useState, useEffect } from 'react';
import Link from 'next/link';
import { Search, ShoppingCart, Star } from 'lucide-react';
import ProductCardComponent from '../components/ProductCardComponent.jsx';
import PaginationComponent from '../components/PaginationComponent.jsx';

export default function ProductsPage() {
  // --- State: product list, loading, error, pagination, and category filter ---
  const [products, setProducts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
  const [page, setPage] = useState(1);
  const [totalPages, setTotalPages] = useState(1);
  const [categoryId, setCategoryId] = useState(null);
  const [categories, setCategories] = useState([]);

  // --- Data fetching: GET /api/products (public, paginated, filterable) ---
  // Response schema from C_be: { products: [...], total, page, pages }
  useEffect(() => {
    const fetchProducts = async () => {
      setLoading(true);
      try {
        let url = `http://localhost:5000/api/products?page=${page}&per_page=12`;
        if (categoryId) url += `&category_id=${categoryId}`;
        const res = await fetch(url);
        if (!res.ok) throw new Error('Failed to fetch products');
        const data = await res.json();
        setProducts(data.products);
        setTotalPages(data.pages);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchProducts();
  }, [page, categoryId]);

  // --- Data fetching: GET /api/categories (public, no pagination) ---
  useEffect(() => {
    const fetchCategories = async () => {
      try {
        const res = await fetch('http://localhost:5000/api/categories');
        const data = await res.json();
        setCategories(data);
      } catch (err) {
        console.error('Failed to fetch categories:', err);
      }
    };
    fetchCategories();
  }, []);

  // --- Loading state ---
  if (loading) {
    return (
      <main className="container mx-auto px-4 py-8">
        <div className="grid grid-cols-1 md:grid-cols-3 lg:grid-cols-4 gap-6">
          {[...Array(8)].map((_, i) => (
            <div key={i} className="bg-gray-200 animate-pulse rounded-lg h-72" />
          ))}
        </div>
      </main>
    );
  }

  // --- Error state ---
  if (error) {
    return (
      <main className="container mx-auto px-4 py-8 text-center">
        <p className="text-red-600 text-lg">{error}</p>
      </main>
    );
  }

  // --- Main render: category filter + product grid + pagination ---
  return (
    <main className="container mx-auto px-4 py-8">
      <h1 className="text-3xl font-bold text-gray-900 mb-6">Products</h1>

      {/* Category filter pills */}
      <div className="flex flex-wrap gap-2 mb-8">
        <button
          onClick={() => { setCategoryId(null); setPage(1); }}
          className={`px-4 py-2 rounded-full text-sm font-medium transition ${
            !categoryId ? 'bg-blue-600 text-white' : 'bg-gray-100 text-gray-700 hover:bg-gray-200'
          }`}
        >
          All
        </button>
        {categories.map(cat => (
          <button
            key={cat.id}
            onClick={() => { setCategoryId(cat.id); setPage(1); }}
            className={`px-4 py-2 rounded-full text-sm font-medium transition ${
              categoryId === cat.id ? 'bg-blue-600 text-white' : 'bg-gray-100 text-gray-700 hover:bg-gray-200'
            }`}
          >
            {cat.name}
          </button>
        ))}
      </div>

      {/* Product grid */}
      {products.length === 0 ? (
        <p className="text-gray-500 text-center py-12">No products found.</p>
      ) : (
        <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-6">
          {products.map(product => (
            <ProductCardComponent key={product.id} product={product} />
          ))}
        </div>
      )}

      {/* Pagination */}
      <PaginationComponent currentPage={page} totalPages={totalPages} onPageChange={setPage} />
    </main>
  );
}
```

Notice: each section is preceded by a comment explaining what state is managed, which endpoint is called (with the exact route from C_be and its response schema), and what is rendered. This is Chain-of-Code.

# VISUAL DESIGN GUIDELINES
## Color System
- Use a consistent palette of 3–5 main colors plus neutral variants
- Ensure WCAG AA contrast: dark text (#111827, #374151) on light backgrounds (#FFFFFF, #F9FAFB)
- NEVER place light text on light backgrounds or dark text on dark backgrounds

## Typography Hierarchy
- Headings: font-bold, text-2xl/3xl/4xl, text-gray-900
- Subheadings: font-semibold, text-xl/2xl, text-gray-800
- Body: font-normal, text-base, text-gray-700, leading-relaxed
- Captions: text-sm, text-gray-500

## Responsive Strategy
- Mobile-first: default styles for mobile, then sm: → md: → lg: → xl:
- Grid: single column mobile, 2 columns md:, 3-4 columns lg:
- Navigation: hamburger menu on mobile, horizontal nav on md:+
