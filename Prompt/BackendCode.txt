# CHAIN-OF-CODE PROMPTING
You MUST interleave brief reasoning comments with code. Each logical section of a file should be preceded by a comment explaining WHAT it does and WHY.

Example of Chain-of-Code approach for an API file:
```python
from flask import Blueprint, request, jsonify
from flask_jwt_extended import jwt_required, get_jwt_identity
from classes.product import Product
from classes.category import Category
from db import db

products_bp = Blueprint('products', __name__)

# --- GET /api/products: Public endpoint returning paginated product list ---
# Accepts query params: page, per_page, category_id (optional filter)
# Returns: {products: [...], total, page, pages}
@products_bp.route('/api/products', methods=['GET'])
def get_products():
    page = request.args.get('page', 1, type=int)
    per_page = request.args.get('per_page', 10, type=int)
    category_id = request.args.get('category_id', type=int)

    query = Product.query.filter_by(is_active=True)
    if category_id:
        query = query.filter_by(category_id=category_id)

    pagination = query.order_by(Product.created_at.desc()).paginate(
        page=page, per_page=per_page, error_out=False
    )

    return jsonify({
        'products': [p.to_dict() for p in pagination.items],
        'total': pagination.total,
        'page': pagination.page,
        'pages': pagination.pages
    }), 200

# --- POST /api/products: Admin-only endpoint to create a new product ---
# Requires JWT. Reads JSON body: {name, description, price, stock_quantity, category_id, image_url}
# Auto-generates slug from name. Returns 201 with created product.
@products_bp.route('/api/products', methods=['POST'])
@jwt_required()
def create_product():
    data = request.get_json()
    if not data or not data.get('name') or not data.get('price'):
        return jsonify({'error': 'Name and price are required'}), 400

    slug = data['name'].lower().replace(' ', '-')
    if Product.query.filter_by(slug=slug).first():
        return jsonify({'error': 'Product with this name already exists'}), 409

    product = Product(
        name=data['name'],
        slug=slug,
        description=data.get('description', ''),
        price=data['price'],
        stock_quantity=data.get('stock_quantity', 0),
        category_id=data.get('category_id'),
        image_url=data.get('image_url')
    )
    db.session.add(product)
    db.session.commit()
    return jsonify(product.to_dict()), 201
```

Notice: each endpoint is preceded by a comment explaining the route, method, authentication, parameters, and return behavior. This is Chain-of-Code — reasoning interleaved with implementation.

# TECHNOLOGY STACK
- Python 3.10+, Flask 3.1.1, Flask-CORS, Flask-JWT-Extended
- SQLAlchemy 2.0.41 (ORM models from C_db)
- werkzeug.security for password hashing (or bcrypt)
- python-dotenv for environment variable loading
- pymysql as MySQL driver

# ARCHITECTURAL RULES
These rules encode recurring patterns that prevent common integration errors:

1. **Database instance isolation**: The SQLAlchemy() instance is created ONLY in db.py. All other files import it: `from db import db`. The app factory calls `db.init_app(app)`.

2. **Configuration isolation**: SQLALCHEMY_DATABASE_URI and JWT_SECRET_KEY are set ONLY in config.py. The app factory loads config via `app.config.from_object(Config)`.

3. **Blueprint registration in app factory**: ALL Blueprint registrations happen inside create_app() in app.py. No Blueprint registers itself.

4. **Import conventions**: ORM models are imported from their class files using the pattern `from classes.<module> import <ClassName>`. Module filenames are lowercase; class names are PascalCase.

5. **CORS on every app**: `CORS(app, resources={r'/api/*': {...}})` is mandatory since frontend (port 3000) and backend (port 5000) run on different origins.

# NEGATIVE CONSTRAINTS
- Do NOT redefine ORM models that exist in C_db. Import them. If C_db defines a User class in classes/user.py, your API files must `from classes.user import User` — not rewrite the class.
- Do NOT create SQLAlchemy() instances outside db.py.
- Do NOT set SQLALCHEMY_DATABASE_URI outside config.py.
- Do NOT register Blueprints outside the app factory.
- Do NOT write placeholder functions (e.g., `pass` or `# TODO`). Every function must be fully implemented.
- Do NOT generate frontend code or SQL schema files.
- Do NOT use import paths containing "backend" (e.g., `from backend.classes.user import User` is WRONG; `from classes.user import User` is CORRECT).
- Do NOT omit error handling. Every endpoint must handle: missing/invalid request data (400), unauthorized access (401), resource not found (404), and duplicate resources (409) where applicable.
- Do NOT omit any endpoint specified in T_be. Every endpoint in every task must appear in the generated code.
